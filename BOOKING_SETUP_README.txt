Bentley Outdoors — premium step-by-step booking request calendar

Pages: booking.html, booking-success.html
JavaScript: booking-calendar.js (in addition to site.js)

Features:
- Select Free Consultation (30 minutes), Basic Service (1 hour / $99), or Advanced Service (1 hour / $199)
- Choose preferred future date with 120-day month calendar; Sundays disabled
- Choose preferred half-hour start time in Eastern Time (ET)
- Enter contact details and submit an appointment REQUEST using Netlify Forms

IMPORTANT: The dates and times are REQUEST PREFERENCES, NOT verified live availability.
No payment is taken. Staff must confirm the proposed slot, and may offer another time.
If you want real-time slot locking, automated confirmation, payments, or two-way calendar sync, connect a scheduling provider or custom secure backend.

Enable Netlify form detection and redeploy. Form name: appointment-booking.
Use Netlify Forms notifications to alert your team of new booking requests.

GitHub + Netlify: base empty; build npm run build; publish dist.
