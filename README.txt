Bentley Outdoors Multi-Page Website

START HERE: Read OPEN_ME_FIRST.txt.

Windows: Double-click start_website.bat after extracting the ZIP.
Mac/Linux: Run python3 serve_website.py from this folder.
Direct fallback: Open index.html in a browser.
The local server automatically picks a free port between 8000 and 8010.

Pages included:
- index.html — Home
- about.html — About the company
- services.html — Services and service detail modals
- projects.html — Project portfolio with category filters and detail modals
- service-areas.html — Service location and availability
- process.html — Project process
- contact.html — Contact / Get a Quote form

Shared assets:
- styles.css — shared responsive styling
- assets.js — logo and landscape image paths
- data.js — services, projects, and process content
- site.js — shared interactions and form behavior
- assets/ — logo and landscape image files

Important notes:
- Before & After has been removed.
- No placeholder-only customer reviews are shown. Add genuine reviews only when available.
- Portfolio images are visual references unless separately verified as completed client projects.
- The inquiry form prepares a message and creates email/WhatsApp links; it does not submit to a backend/database.
- Verify business contact details, certifications, and service coverage before publishing.
- This package is not a public live URL. Upload the entire folder to a web host to publish it.
