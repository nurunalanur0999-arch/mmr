Bentley Outdoors premium Service Areas map

Service areas shown: Marietta, Roswell, Buckhead, Canton, Kennesaw, Acworth, Alpharetta (Georgia, USA).
The Service Areas page is a separate geographic coverage page. The six actual services remain on Services page.

Features:
- Seven accessible locations, approximate central points; not exact service boundaries.
- Independent, offline-visible vector map plus interactive Leaflet/OpenStreetMap tiles when internet is available.
- City selector, selected location, Open Google Maps, quote button, and Show all.
- No Google Maps API key or subscription required.
- Leaflet CSS and JS load from unpkg.com. OpenStreetMap tiles load from tile.openstreetmap.org. If blocked/offline, the built-in schematic stays visible.
- To test local: python -m http.server 8080 and open http://localhost:8080/service-areas.html.
- Netlify build: npm run build, publish dist, base blank.

The map pins indicate approximate city centers only; customer address and project availability must be confirmed directly.
